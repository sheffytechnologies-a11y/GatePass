# CheckPass Web Portal & Landing Website

Frontend application for **CheckPass — Modern Estate Access Management OS**.

## Technology Stack
- **Framework:** Vue 3 Composition API (`<script setup>`)
- **Language:** TypeScript
- **Bundler:** Vite 5
- **Routing:** Vue Router 4 (HTML5 Web History)
- **State Management:** Pinia
- **Icons:** Phosphor Duotone Icons (`@phosphor-icons/web`)
- **Animation & Physics:** GSAP 3 + ScrollTrigger + Lenis Smooth Scroll + Framer Motion-style Spring Physics

## Directory Layout
- `src/views/LandingView.vue` — Main marketing website (Hero, How It Works, Features Bento Slider, Pricing ROI Calculator, Stakeholder Showcase, FAQ, Contact)
- `src/views/DashboardView.vue` — Estate Manager Administrative Operations Console
- `src/views/CrmView.vue` — Super Admin Sales Pipeline & AI Concierge Lead Management
- `src/views/RegisterView.vue` — Estate Onboarding & Sign-up Portal
- `src/views/LoginView.vue` — 3-Role Unified Login (Estate Manager, Resident, Guard Station)
- `public/landing.css` — High-performance responsive stylesheets and keyframe animations
- `public/docs/` — Regulatory Compliance Documents (Master Services Agreement & DPA PDF)
